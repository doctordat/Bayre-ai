# VietnamGo — Attraction Content Map

## Guide model

Every attraction page should answer: **what is it, why go, who is it for, how long, ticket status, how to buy/check tickets, how to get there, nearby links, planner preset and contextual CTA**. Ticket prices/opening hours must be checked against the official venue before publication; use “check current ticket information” when not verified.
